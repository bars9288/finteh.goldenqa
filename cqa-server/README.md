# CQA Server

Spring Boot приложение: поднимает контекст и веб-слой.

`ru.cqa.server` · артефакт `cqa-server` · [← к карте проекта](../README.md)

## Назначение

Точка входа приложения. Единственный модуль, который знает про Spring:
поднимает контекст, собирает бины остальных модулей и отдаёт наружу веб-слой.

## Зависимости

### Внутренние

_Пока нет._ Модуль не зависит ни от одного другого модуля проекта.

### Внешние

| Зависимость               | Назначение                          |
|---------------------------|-------------------------------------|
| `spring-boot-starter-web` | Spring MVC на встроенном Tomcat     |
| `spring-boot-starter-test`| тесты (scope `test`)                |

BOM `spring-boot-dependencies` **4.1.1** импортируется в этом модуле, а не в
корне, — поэтому остальные модули остаются свободными от Spring.

## Сборка и запуск

```bash
mvn -pl cqa-server spring-boot:run
java -jar target/cqa-server-0.0.1-SNAPSHOT.jar
```

`spring-boot-maven-plugin` выполняет `repackage`, на выходе — исполняемый
fat-jar со `Start-Class: ru.cqa.server.CqaServerApplication`.

## Конфигурация

`application.yml` лежит в корне репозитория; плагин запускается с
`workingDirectory=${project.basedir}/..`. Подробности и переменные — в
[корневом README](../README.md#конфигурация).
